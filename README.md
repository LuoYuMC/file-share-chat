# 文件分享 & 聊天（单文件 exe，Windows 10）

**无需安装 Python 或任何运行环境**，双击 `file-share-chat.exe` 即可运行。
网页（HTML）已经编译进 exe 内部，无需额外文件。

## 一键运行

1. 解压 ZIP，得到 `file-share-chat.exe` 和 `files` 文件夹。
2. **双击 `file-share-chat.exe`**。
3. 弹出 UAC 窗口时点击“是”（修改 hosts 文件需要管理员权限，程序会自动以管理员身份重新启动）。
4. 程序会自动配置防火墙、启动服务，并打开聊天页面 `http://localhost:2147/`。
5. 停止服务：在程序窗口中按 `Ctrl+C`（会自动恢复 hosts 文件）。

> 如果 Windows SmartScreen 提示“无法识别的应用”，点击“更多信息” → “仍要运行”即可（未做代码签名）。

## 端口与访问地址

程序同时监听两个端口：

| 端口 | 用途 | 本机访问示例 |
|---|---|---|
| **2147** | 聊天、文件预览、公告、浏览、账号与管理页面 | `http://localhost:2147/` |
| **80** | 提示页：局域网设备或域名（hosts 列表中的域名）访问时显示 | `http://localhost/` |

- 80 端口的提示页显示一段提示文字、一个可编辑的访问地址框，以及“前往聊天”按钮（地址由主管理员或副管理员设置，见下文）。访问地址与“前往聊天”都在当前页面打开。
- 如需修改端口，可在命令行中使用 `-port`（聊天端口，默认 2147）和 `-notice-port`（提示页端口，默认 80）。

## 功能

### 1. 聊天
- **最新消息预览**：每个会话（大群、小群、私聊）名称下方显示灰色的最新消息预览，超过 20 字的部分用 `...` 代替。我发送的消息前显示“我：”，群聊中显示发送人名称；HTML 消息显示为 `[HTML消息]`，群邀请显示为 `[群邀请]`，已撤回的消息显示为 `消息已撤回`。
- **聊天记录搜索**：聊天标题栏右侧的“搜索”按钮默认只搜索当前会话（大群、某个小群或某个私聊）中的文字消息；勾选搜索框旁的“搜索全局”可搜索全部大群、小群和私聊（“搜索全局”每次打开搜索时默认关闭；不区分大小写，按时间从新到旧，每次显示 100 条，结果底部点击“加载更多”可继续显示更早的结果）。点击结果会切换到该会话，并自动向上翻页加载，定位到该消息并高亮。HTML 消息、群邀请和已撤回的消息不参与搜索。
- **大群聊天**：所有登录用户共享一个群聊。在大群或小群中输入 `@` 会弹出成员列表（小群中为本群成员），列表第一项为 **所有人**（选择后插入 `@所有人`，提醒全体成员）；选择成员后插入 `@用户名`。被 @ 的用户会在消息气泡上看到高亮提示，@所有人 的消息同样高亮。
- **快速 @**：点击大群或小群中别人发送的消息，即可把 `@他` 插入输入框（大群与小群中均有效）。
- **群聊排序与红点**：大群与小群统一按**最后一条消息时间由新到旧**排序（小群可以排在大群上面）。大群和小群只要有他人发来的新消息（不需要 @），左侧对应条目右上角就显示红点；打开该群后消失。
- **私聊**：左侧会话栏列出全部用户，点击即可与其私聊。管理员不能查看其他人之间的私聊。
- **未读数**：私聊和小群的未读消息条数显示在左侧会话条目右上角的红色徽标中（超过 99 显示 99+），打开该会话后消失。**大群只显示红点，不显示数字**。当有人在未读消息中 @ 你（或 @所有人）时，小群和大群的红点文字显示为 “@”（代替数字）；打开该会话后消失。“私聊”列表**始终按最新消息排序**（从新到旧）。
- **消息菜单**：点击任意消息（包括自己发送的）弹出菜单：**复制**（复制消息内容）、**引用**（输入框下方出现引用条，发送后该消息下方显示灰色的引用框，内容只显示一行，超出部分以 `...` 代替）；在大群和小群中点击别人的消息还可选 **@TA**；在大群和小群中引用别人的消息时，输入框会同时插入对方的 `@用户名`（引用自己的消息不插入）。 主/副管理员在大群中点击他人的消息时，菜单最后是红色的 **禁言**（大群禁言，只影响大群；该用户已被大群禁言，或为主管理员时不显示）。小群的消息菜单中没有“禁言”，小群禁言在成员详情中操作。
- **HTML 消息**：**只有主管理员和副管理员可以发送**。发送时在输入框左侧选择 **HTML** 类型（普通用户看不到该选项，只能发送纯文本）；所有用户都可以查看 HTML 消息。纯文本与 HTML 消息均最多 **30000 字符**。聊天中显示蓝色的“HTML消息，点击查看。”，点击后菜单中的“复制”变为“打开”，在屏幕中央的窗口中打开（左上角“← 返回”关闭；按 Esc 也可关闭）。
- **草稿**：每个会话（大群、每个私聊对象）未发送的文字会保存在本浏览器中，切换会话后自动恢复，发送后清除。
- **切换页面不丢消息**：私聊消息按对象缓存在页面中，切换到其他标签再返回聊天时，历史消息立即显示。
- 红点的已读位置保存在本浏览器中（同一账号换浏览器会重新计算）；首次进入时，已有的消息不会显示红点。
- 气泡宽度随文字长短变化；输入框随内容自动增高，最多 4 行，超出后滚动。**Enter 发送，Shift+Enter 换行。**
- **放大输入框**：输入框右上角的放大按钮始终可见。放大后输入框覆盖除顶栏外的全部区域，消息类型与发送按钮位于输入框右下角；此时 **Enter 为换行**；点击按钮或按 **Esc** 收起，收起后 Enter 恢复为发送。放大时仍可输入 `@` 选人：选择框打开时 Enter 选人，按 Esc 先关闭选择框。
- **全局禁言**：管理员（主/副管理员）禁言用户后，该用户仍可查看大群、小群与私聊消息，但**私聊、大群和所有小群都不能发言**（输入框、类型选择与发送按钮均不可用，并显示提示）。解除禁言后立即恢复。设置方式见下文“管理员与副管理员”。
- **大群禁言**：管理员可单独禁言用户的大群发言（只影响大群：输入框与发送按钮不可用，仍可查看大群消息）。**不影响私聊与小群**。主/副管理员可在大群成员详情、用户管理或大群消息菜单中设置；解除后立即恢复。大群禁言与全局禁言互相独立，解除其中一个不影响另一个。
- **撤回**：自己发送的消息（大群、私聊、小群）在 **2 分钟内** 可在消息菜单中点 **撤回**。撤回后该消息显示为灰色的“消息已撤回”，其他人会在数秒内看到，引用它的消息，引用框只显示“原消息已被撤回”。超过 2 分钟的消息不能撤回。
- **黑名单（仅私聊）**：在私聊标题右侧点 **⋯** → **加入黑名单**，对方将无法再向你发送私聊消息（单向生效：你仍可以给对方发消息）。再次点 ⋯ 可移出。大群没有黑名单功能。被拉黑的用户在你的私聊列表中显示“已拉黑”标记。
  - **被对方拉黑时**：你与对方的私聊中，输入框、类型选择与发送按钮会被禁用，并显示“对方已将你加入黑名单，暂时不能发送私聊消息”（与被禁言时的显示方式相同）。大群与你和其他用户的私聊不受影响；对方解除黑名单后自动恢复。
- **小群**：在左侧“群聊”标签右侧点 **+** 新建小群（群名 1-20 字）。主管理员和副管理员可以无限制创建小群；其他非“待处理”用户默认最多可创建 **1 个**小群（管理员可在用户详情中调整数量，见下文）。若数量设置得小于该用户已创建的群数，只是禁止再创建，已有的小群**不会**被解散。小群在左侧列表中与大群一起按最后一条消息时间排序，有新消息时显示红点。
  - **群主**：在小群标题右侧点 **⋯**，可 **拉入用户**（见下方“群邀请”）、**重命名**，或 **解散小群**（红色选项，位于菜单最后；解散后该群及其全部消息被删除，成员将无法再访问）。群主**不能退出**自己的小群。禁言与踢出在成员详情中操作（见下方“成员列表”）。
  - **成员**：在小群标题右侧点 **⋯** → **退出群聊**。
  - 新拉入的成员可以看到小群的全部历史消息。
  - **小群禁言只影响该群**，与全局禁言互不影响。
- **成员列表**：大群与小群标题右侧的 **⋯** 中都有 **成员列表**，所有用户均可查看。大群成员列表为全部非“待处理”用户；小群成员列表中群主置顶，并带蓝色“群主”标记（仅在该列表中显示）。点击成员进入详情，详情只显示用户名、身份、别名与状态，并可直接**私聊**该用户。用户名右侧会显示红色禁言标志，每人最多显示一个，**全局禁言优先**（同时被全局禁言和大群禁言时只显示“全局禁言”）：私聊列表与大群成员列表显示“全局禁言”或“大群禁言”；小群成员列表显示“全局禁言”或“本群禁言”（小群群主仍显示蓝色“群主”）。待处理账号不显示在私聊列表中。
  - 小群群主在成员详情中可对成员 **禁言 / 解除禁言**（只影响本小群，与全局禁言互不影响）以及 **踢出**（群主不能被禁言或踢出）。
  - 主/副管理员在大群成员详情中可对用户 **大群禁言 / 解除大群禁言**（只影响大群）与 **全局禁言 / 解除全局禁言**（私聊和所有群聊）；主管理员账号不能被禁言。
- **群邀请**：群主拉入用户时不会直接入群，而是向对方发送一条蓝色的“邀请你进入xxx”消息（显示在私聊中）。对方点击该消息并确认同意后即加入小群；同意后该邀请只能使用一次。以下情况不能被邀请：待处理用户、已在群中的用户、已将群主加入黑名单的用户。小群已解散后，该邀请无法再同意。
- **历史消息与分页**：聊天记录不再限制条数，所有消息都会保存。进入聊天时只显示最近 100 条，点击顶部的 **加载更早的消息** 可分页查看更早的记录。
- **待处理账号**：新注册、尚未被管理员处理的账号处于全局禁言状态，且不出现在私聊列表、成员列表与拉入列表中
- **用户名显示**：消息中显示的是用户当前的用户名，修改用户名后历史消息同步更新；引用框中的用户名保留发送引用时的快照。

### 2. 文件预览
- 进入“文件预览”页，点击列表中的某个文件，预览区会出现在文件列表下方。
- 支持预览 **图片**（png、jpg、jpeg、gif、webp、bmp）、**视频**（mp4、webm、ogv、mov；能否播放取决于浏览器是否支持该编码，视频预览区有“全屏”按钮，也可使用播放器自带的全屏按钮，按 Esc 退出）、**音频**（mp3、wav、flac、ogg、oga、opus、m4a、aac；可播放和拖动进度）和 **文本文件**（txt、md、csv、json、log、html、代码等常见文本格式，不超过 2 MB）。
- **文本文件**显示在一个文本框中，可以直接修改，但修改**只在当前页面有效**：页面没有保存或提交按钮，修改不会写入服务器；重新选择文件后恢复为服务器上的原内容。文本按 UTF-8 解码，不是 UTF-8 时按 GBK / GB18030 解码（兼容 Windows 下保存的中文文本）。
- 文本文件中若包含二进制内容（如改了后缀的程序或压缩包），或超过 2 MB，则提示无法预览。
- 其他类型的文件（如 exe、zip、docx、pdf）**无法查看，也不提供下载**。
- 将文件放入 `files` 文件夹（支持子文件夹），在页面点“刷新列表”即可看到。

### 3. 解析域名列表（hosts）
- 由**管理员**在“管理”页的“域名解析列表”中维护：每个域名可指定目标 IP（留空默认 `127.0.0.1`），可随时修改 IP。
- 列表中的每个域名都会写入 `C:\Windows\System32\drivers\etc\hosts`，例如：
  `192.168.1.50 share.local # [file-share-chat]`
- 程序运行期间记录一直有效，添加或删除后立即生效；停止程序时，全部由本程序写入的记录自动恢复。
- 通过列表中的任一域名访问（如 `http://share.local/`，无需端口号）时，显示 80 端口的提示页。
- 注意：
  - 不要添加正在使用的真实网站域名，否则该网站在本机无法打开；
  - 不要使用 `.dev`、`.app`、`.page`、`.new`、`.foo` 等结尾的域名（浏览器会强制 HTTPS，无法访问）；
  - 最多 50 个域名；重复添加会提示。

### 4. 浏览
- “浏览”页默认地址为 `https://bing.com/`。输入内容后点击“打开”，网页显示在页面下方的框架中（不再开新标签页）：
  - 域名或 IP（如 `example.com`、`192.168.1.20:8080`）：直接打开（默认 `http://`；如需 https，请直接输入 `https://域名`）；
  - 其他内容：使用 Bing 搜索。
  - 框架下方的“全屏”按钮可将网页放大至整个窗口，左上角“← 返回”退出全屏（不会重新加载网页）。
  - 部分网站禁止被嵌入显示，会在框架中显示错误页。Bing 首页（`bing.com`）属于这类网站，无法在框架中显示；Bing 搜索结果页可以正常显示。
- 80 端口提示页上的访问地址框使用同样的规则，并在当前页面打开。

### 5. 公告
- “公告”页对所有用户公开可见。
- 只有主管理员和副管理员可以发布和删除公告；禁言不影响公告；HTML 公告的显示高度会随内容自动调整。

### 6. 账号管理与别名
- **注册**：设置用户名与密码（密码 6-128 位）。**新注册用户默认被禁言**（私聊和所有群聊均不能发言），需管理员处理后才能发言。用户名 `admin` 与 `所有人` 为系统保留，普通用户无法注册或改为这两个名字。
- **账号管理**页（原“账号与密码”）：
  - **修改密码**（修改后，该账号在其它设备上的登录失效）；
  - **修改用户名**：只需保持登录，无需输入密码；用户名不能与其他用户重复（不区分大小写）；
  - **注销账号**：需连续确认两次。注销后账号无法登录，历史消息保留；你作为群主的小群会转交给群内其他成员，若群内没有其他成员则该小群被解散；
  - **退出登录**。
  - 主管理员账号的用户名不可修改，也不能注销。
- **登录用户名下拉**：登录界面的用户名输入框下方列出本浏览器登录过的用户（显示用户名和别名）。输入时按用户名或别名筛选，未输入则列出全部；无匹配时不显示。点击即可填入。该列表保存在浏览器本地，不会从服务器获取全部用户。
- **别名**：管理员可以为用户设置别名（1-20 位），别名以灰色小字显示在用户名后面，仅用于显示，不影响登录。

### 7. 管理员与副管理员
- **主管理员**：用户名 `admin`，**默认密码 `admin123`**，首次启动自动创建。请登录后立即在“账号管理”中修改密码。用户名 `admin` 为系统保留，普通用户无法注册。
- **副管理员**：由主管理员在“用户管理”中指定。副管理员拥有除以下操作外的全部管理权限：**不能设置或取消副管理员、删除账号、修改域名解析列表（hosts）和 80 端口提示页**（这些页面对副管理员不显示）。副管理员仍可禁言、设置别名、设置小群数量、发布公告。
- “用户管理”列表可点击表头排序（再次点击反向）；别名、禁言、副管理员、删除账号等操作均在 ⋯ 详情页中进行（副管理员看不到仅主管理员可用的操作，如删除账号、设置副管理员）。
- 管理员可以：
  - **大群禁言 / 解除大群禁言**用户（只影响大群发言，私聊和小群不受影响；主管理员账号不能被禁言）。可在用户详情中操作，也可在大群成员详情或大群消息菜单中操作；
  - **全局禁言 / 解除全局禁言**用户（私聊和所有群聊均不能发言；主管理员账号不能被禁言）。可在用户详情或大群成员详情中操作；
  - **设置用户可创建的小群数量**：在用户详情中填写非负整数（默认 1，填 0 表示不允许再创建）。主管理员和副管理员不受此限制；已有的小群不会被解散；
  - **设为 / 取消副管理员**（仅主管理员；主管理员身份不可更改）；
  - **设置别名**；
  - **删除账号**（仅主管理员）：在“用户管理”中点击用户行最右侧的 ⋯ 打开用户详情，再点击“删除账号”，需在页内确认框中连续确认两次。删除后该账号无法登录，其历史消息保留；不能删除自己，也不能删除主管理员账号；
  - 维护域名解析列表（仅主管理员）；
  - **设置 80 端口提示页**（仅主管理员）：
  - **解散用户创建的小群**（仅主管理员）：在用户详情的“该用户创建的小群”中可解散该用户作为群主的小群。解散后该群及其全部消息被删除；主管理员不能查看群内消息。
  - 发布与删除公告。
- **待处理红点**：新注册用户未被管理员处理时，“管理”标签上显示红点，用户管理表中标记为“待处理”。管理员解除全局禁言即完成处理（之后再次禁言不会重新出现待处理）。待处理账号在用户列表中仍可见，但不会出现在其他用户的私聊与拉入列表中。
- **管理页面**：访问 `http://localhost:2147/`，登录管理员账号后点击“管理”标签。
- **忘记管理员密码**：关闭程序，用记事本打开 `data\app.json`，删除用户名为 `admin`（`"is_admin": true`）的那一整个 `{ ... }` 对象，保存后重新启动，程序会重新创建 `admin`（默认密码 `admin123`）。

## 其他电脑访问

- 局域网内其他设备访问 `http://服务器IP:2147/` 使用聊天、公告、预览和账号功能；访问 `http://服务器IP/` 显示 80 端口的提示页，并可从提示页前往聊天。程序已自动添加 2147 和 80 端口的防火墙入站规则。
- 列表中的域名只对修改了 hosts 的电脑生效。其他电脑若也要通过域名访问，需在它们自己的 hosts 中为每个域名各添加一行：`服务器IP  域名`。

## 常见问题

| 现象 | 处理 |
|---|---|
| 提示“提升权限失败” | 没有点击 UAC 的“是”。重新双击 exe 并确认。 |
| 提示“无法写入 hosts” | ①右键 exe →“以管理员身份运行”；②hosts 文件是否为只读（程序会自动清除，仍失败则手动取消只读）；③关闭或设置 360、腾讯电脑管家等安全软件的 hosts 保护，把本程序加入信任；④Windows 安全中心 → 病毒和威胁防护 → 勒索软件防护，允许本程序。页面上会显示需要手动添加的记录，用记事本以管理员身份打开 `C:\Windows\System32\drivers\etc\hosts` 添加即可。 |
| 提示“无法监听端口 2147” | 2147 端口被占用：其他程序，或之前未退出的本程序。关闭占用它的程序后再试。 |
| 提示“无法监听提示页端口 80” | 80 端口被占用：IIS、其他网站服务，或之前未退出的本程序。关闭占用它的程序后再试；或使用 `-notice-port` 指定其他端口（此时域名访问需要带端口号）。 |
| 添加域名后提示“hosts 写入失败” | 域名已保存到列表，但没有写入 hosts。页面会列出需要手动添加的记录，按上一行的方法手动添加即可。 |
| 访问域名没有反应 | `ipconfig /flushdns` 或重启浏览器；确认域名不是 `.dev` / `.app` 等结尾。 |
| 程序被直接关闭（没按 Ctrl+C） | hosts 中可能残留记录，下次启动会自动清理。 |
| 重启程序后要重新登录 | 登录状态保存在 `data\sessions.json` 中，重启程序后仍保持登录（7 天内有效，与原来的登录有效期相同）。修改密码或注销账号后，该账号在其它设备上的登录会失效；删除 `sessions.json` 可清除所有登录状态。 |

## 安全说明

- 通信为 HTTP 明文，请只在可信网络中使用（聊天内容与密码会在网络中明文传输）。
- 文件预览只对登录用户开放，只允许图片、视频、音频和文本类型；文本以 `text/plain` 返回，HTML、JS、SVG 不会在页面中执行。文本预览为只读接口，没有任何写入服务器的功能。请只放入可以公开给成员查看的文件。
- 80 端口只提供提示页，不提供任何接口或文件。提示页中的“前往聊天”地址由管理员设置，请只填写可信的地址。
- 密码以 PBKDF2-HMAC-SHA256（20 万次迭代 + 随机盐）哈希保存在 `data\app.json`，不保存明文。

## 重新编译（可选）

需要安装 Go 1.22+（https://go.dev/dl/），在 `source` 目录下执行：

```
set CGO_ENABLED=0
set GOOS=windows
set GOARCH=amd64
go build -trimpath -ldflags "-s -w" -o file-share-chat.exe .
```

编译完成后，把生成的 `file-share-chat.exe` 与 `files` 文件夹放在同一目录即可。
页面源文件位于 `source\static\index.html`（聊天与管理页面）和 `source\static\notice.html`（80 端口提示页），修改后重新编译即可生效（均已通过 go:embed 编译进 exe）。
